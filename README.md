Capacidades

- [x] 10 botones asignables
        * Abrir programa / URL
        * Atajo / Macro de teclado
        * Teclas multimedia
        * Silenciar aplicacion
        * Silenciar microfono
        * Silenciar master
        * Cambiar salida de audio
        * Cambiar micrófono predeterminado
- [x] 5 sliders (Control de volumen)
        * Volumen master
        * Volumen Microfono
        * Volumen aplicacion
        * Volumen dispositivo de audio
        * Volumen ventana activa
        
- [x] Opcional Tira de LEDs interior
        * Arcoíris
        * Color fijo
        * Color Personalizado

- [x] Opciones
        * Selección automática de puerto COM
        * Iniciar con Windows (Minimizado en la bandeja)
